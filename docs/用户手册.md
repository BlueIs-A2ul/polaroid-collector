## 1. 应用简介

电子切盒是一个拍立得记录管理应用，帮助用户：

- 记录偶像拍立得照片（正面、背签）
- 追踪购买价格和消费统计
- 按偶像、团体、城市等维度分析收藏
- 生成年度报告和个人报告
- 导入导出数据，备份恢复

### 主要功能

| 功能 | 说明 |
|------|------|
| 单张/批量上传 | 支持多张照片一次性添加 |
| 花费追踪 | 记录每笔消费的金额 |
| 统计分析 | 排行、消费趋势、分类统计 |
| 日历视图 | 按日期浏览拍立得记录 |
| 年度报告 | 8页年度回顾（类Spotify Wrapped风格） |
| 偶像报告 | 单个偶像的年度统计 |
| 主题切换 | 6种预设主题 + 自定义 |
| 数据备份 | JSON/CSV导出、完整备份恢复 |
| 整理中心 | 检查疑似重复记录和待补信息 |

## 2. 快速开始

### 安装应用

**方式一：Expo Go（推荐）**

1. 在手机应用商店下载 **Expo Go**
2. 运行 `npm start` 启动开发服务器
3. 用 Expo Go 扫描终端显示的二维码

**方式二：构建安装包**

```bash
# Android
eas build -p android --profile preview

# iOS
eas build -p ios --profile preview
```

### 首次使用

1. 打开应用后进入**主页**
2. 点击右下角 **+** 按钮添加第一条记录
3. 选择照片、填写信息、保存
4. 开始在主页管理你的收藏

## 4. 添加记录

点击主页右下角 **+** 按钮进入上传页面。

### 单张上传

1. **选择照片**
   - 点击“拍照”使用相机
   - 点击“单张”从相册选择一张照片
   - 点击“多张”从相册批量选择照片

2. **编辑照片**
   - 可选择是否启用裁切
   - 启用裁切后可调整宽高比
   - 确认后进入下一步

3. **填写信息**

| 字段 | 说明 | 必填 |
|------|------|------|
| 偶像名 | 偶像姓名 | ✅ |
| 团体 | 所属团体 | - |
| 张数 | 本次记录的张数 | 默认1 |
| 拍摄日期 | 照片拍摄日期 | ✅ |
| 价格 | 购买价格（元） | - |
| 城市 | 城市 | - |
| 场馆 | 场馆 | - |
| 类型 | 无签/带签/主题/宿题 | - |
| 人数 | 单人/双人/团切 | - |
| 备注 | 补充说明 | - |

4. **保存**：点击保存完成

### 智能默认值

- 从偶像详情页进入上传时，会自动带入偶像名称
- 如果该偶像绑定过团体，会自动填入团体
- 如果该偶像有历史价格，会自动推荐常用价格
- 价格选择器会展示最多 5 个历史价格，也可以手动输入

### 批量上传

1. 点击“多张”
2. 一次选取多张照片
3. 选择是否合并为一条记录
4. 填写公共信息（团体、城市、场馆会应用到所有照片）
5. 为每张照片分别填写数量、价格、备注、类型、人数和背签
6. 保存

### 背签照片

上传和编辑时都可以为照片添加**背签照片**（偶像签名照背面）。详情页全屏查看照片时，可在正面和背签之间切换。

## 6. 记录编辑

在偶像详情页点击单条记录，进入编辑页面。

### 可编辑字段

所有上传时可填写的字段均可在此修改：

- 城市、场馆、类型、人数

## 13. 整理中心

入口：**主页 → 更多选项 → 整理中心**

整理中心用于帮助你定期清理记录质量，不会自动修改或删除数据，所有处理都需要你进入详情页或编辑页确认。

### 总览信息

页面顶部会显示：

| 指标 | 说明 |
|------|------|
| 疑似重复组 | 同偶像、同日期聚合出的疑似重复记录组 |
| 待补记录 | 缺少关键信息的记录数量 |
| 待补字段 | 所有待补字段的总数 |

### 疑似重复

疑似重复会按**偶像名称 + 拍摄日期**聚合。每组会显示：

- 可信度：高可信、中可信、待确认
- 涉及记录数
- 总张数
- 总价格（如有）
- 判断原因，例如同偶像同日期、价格或地点相近

点击疑似重复卡片会进入该偶像详情页，你可以人工确认是否需要编辑、合并或删除。

### 待补信息

待补信息会检查每条记录是否缺少：

- 团体
- 城市
- 场馆
- 价格
- 背签照片
- 备注
- 拍立得类型
- 人数

点击待补记录会进入编辑页，补充后返回整理中心即可刷新查看。

## 14. 常见问题

### Q: 数据存储在哪里？
A: 数据存储在设备本地，通过 AsyncStorage 持久化。定期备份以防数据丢失。

### Q: 如何添加背签照片？
A: 在上传页面可以为每张照片添加背签；在记录编辑页面也可以单独添加、更换或删除背签照片。

### Q: 批量上传的照片会合并吗？
A: 可选择合并为一条记录，或保留为多条独立记录。

### Q: 整理中心会自动删除重复记录吗？
A: 不会。整理中心只提供疑似重复和待补信息提示，所有修改都需要你进入详情页或编辑页手动确认。

### Q: 支持哪些平台？
A: 支持 iOS、Android 和 Web 三个平台。

### Q: 如何重置主题？
A: 在主题设置页面，选择任意预设主题即可覆盖当前主题。

### Q: 统计数据准确吗？
A: 统计基于所有记录实时计算，数据准确可靠。
