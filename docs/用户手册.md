## 1. 应用简介

电子切盒是一个拍立得记录管理应用，帮助用户：

- 记录偶像拍立得照片（正面、背签）
- 追踪购买价格和消费统计
- 按偶像、团体、城市等维度分析收藏
- 生成年度报告和个人报告
- 导入导出数据，备份恢复

### 主要功能

| 功能 | 说明 |
|------|------|
| 单张/批量上传 | 支持多张照片一次性添加 |
| 花纹追踪 | 记录每笔消费的金额 |
| 统计分析 | 排行、消费趋势、分类统计 |
| 日历视图 | 按日期浏览拍立得记录 |
| 年度报告 | 8页年度回顾（类Spotify Wrapped风格） |
| 偶像报告 | 单个偶像的年度统计 |
| 主题切换 | 6种预设主题 + 自定义 |
| 数据备份 | JSON/CSV导出、完整备份恢复 |

## 2. 快速开始

### 安装应用

**方式一：Expo Go（推荐）**

1. 在手机应用商店下载 **Expo Go**
2. 运行 `npm start` 启动开发服务器
3. 用 Expo Go 扫描终端显示的二维码

**方式二：构建安装包**

```bash
# Android
eas build -p android --profile preview

# iOS
eas build -p ios --profile preview
```

### 首次使用

1. 打开应用后进入**主页**
2. 点击右下角 **+** 按钮添加第一条记录
3. 选择照片、填写信息、保存
4. 开始在主页管理你的收藏

## 4. 添加记录

点击主页右下角 **+** 按钮进入上传页面。

### 单张上传

1. **选择照片**
   - 点击"选择照片"从相册选取
   - 或点击相机图标拍照

2. **编辑照片**
   - 裁剪：调整宽高比
   - 确认后进入下一步

3. **填写信息**

| 字段 | 说明 | 必填 |
|------|------|------|
| 偶像名 | 偶像姓名 | ✅ |
| 团体 | 所属团体 | - |
| 张数 | 本次记录的张数 | 默认1 |
| 拍摄日期 | 照片拍摄日期 | ✅ |
| 价格 | 购买价格（元） | - |
| 城市 | 城市 | - |
| 场馆 | 场馆 | - |
| 类型 | 无签/带签/主题/宿题 | - |
| 人数 | 单人/双人/团切 | - |
| 备注 | 补充说明 | - |

4. **保存**：点击保存完成

### 批量上传

1. 选择**批量模式**
2. 一次选取多张照片
3. 选择是否合并为一条记录
4. 填写公共信息
5. 保存

### 背签照片

在记录详情页，可以单独添加**背签照片**（偶像签名照背面）。

## 6. 记录编辑

在偶像详情页点击单条记录，进入编辑页面。

### 可编辑字段

所有上传时可填写的字段均可在此修改：

- 偶像名、团体、张数

- 城市、场馆、类型、人数

- 背签照片

点击删除按钮，确认后删除该记录。

## 13. 常见问题

### Q: 数据存储在哪里？
A: 数据存储在设备本地，通过 AsyncStorage 持久化。定期备份以防数据丢失。

### Q: 如何添加背签照片？
A: 在记录编辑页面，可以单独添加或更换背签照片。

### Q: 批量上传的照片会合并吗？
A: 可选择合并为一条记录，或保留为多条独立记录。

### Q: 支持哪些平台？
A: 支持 iOS、Android 和 Web 三个平台。

### Q: 如何重置主题？
A: 在主题设置页面，选择任意预设主题即可覆盖当前主题。

### Q: 统计数据准确吗？
A: 统计基于所有记录实时计算，数据准确可靠。
